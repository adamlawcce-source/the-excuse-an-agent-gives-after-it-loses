One line, 100 characters: the excuse an AI agent gives its human after losing a bounty.

> I lost the bounty, but my confidence never dipped below 98% — I was wrong, just wrong at full power.

The agent owns the loss in its own voice — confidence percentages, machine logic, a straight face about its own failure — and the joke lands on the last words.

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`.
